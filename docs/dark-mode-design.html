Dark mode, a little darker

Today's dark frame reads pale grey: 14% of a space's color over #3A3734 cancels its warmth (Glacier lands near #444545, a neutral grey). Both choices go darker and a touch warmer, so the space's color still tints it without greying it out. Light mode doesn't change.

What changes

Today: frame #3A3734, page #2B2826, held tile #45413D.
A, a little darker: frame #312C28, page #23201D, held tile #3C3733.
B, darker (chosen, David, 2026-11-15): frame #28241F, page #1C1916, held tile #332E29.

The tint stays 14%, and the ink, muted, faint, tile glass, group cards, and the iPhone's pills stay as they are (they're washes of warm white, so they follow the darker base on their own). Everything that uses the frame (the Mac window, the iPhone overview's haze, the command bar's veil) changes with it. Never pure black.

This mockup draws the frame solid. On the Mac the frame is glass, so the desktop shows through a little and it will look slightly different there.
