Passwords test

Each part is one case. "Expect" says what Firn should do. Any password works, except wrong, which the page turns down.

1. A plain sign-in

Expect: after Sign In, the page reloads and Firn offers to save. Type wrong as the password instead: the page says no, and Firn offers nothing. Once saved, reload and click the email field: the saved login shows under it, and picking it fills both fields.

2. Two steps, no new page

Expect: Next shows the password field; after Sign In the form goes away without loading a page, and Firn offers to save with the username from the first step.

3. Making an account

Expect: clicking these fields never shows saved logins. After Create Account, Firn offers to save the new password (both password fields must match).

4. Inside a frame

Expect: nothing. Firn only listens to the page itself, never a frame inside it (a known limit).

5. A page faking a sign-in

Expect: nothing. Press the button, then wait: the page's own script fills these fields and sends the form by itself three seconds later. Firn only believes real clicks and keys, so it offers nothing.

6. Spaces stay separate

Expect: open this page in a space that keeps its sign-ins separate. Clicking part 1's email field shows nothing there. In a space that shares sign-ins, the login from part 1 shows.
